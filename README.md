# Sinzo Frontend

Sinzo Frontend is a modern e-commerce frontend application built for an online shopping platform. It provides a clean user interface for browsing products, viewing categories, managing cart items, placing orders, and interacting with product details smoothly.

Live Site: https://sinzo-frontend-dev-w4wv.vercel.app

## Project Overview

This project is developed as the frontend part of the Sinzo e-commerce platform. The main goal of this frontend is to provide users with a fast, responsive, and user-friendly shopping experience.

The website includes product listing, category-based product browsing, product details, cart functionality, order placement, and user dashboard related features.

## Features

- Modern and responsive e-commerce UI
- Product listing and product details page
- Category based product filtering
- Cart management system
- Order placement functionality
- User dashboard and order tracking
- API integrated frontend
- Clean component based structure
- Fully responsive layout for mobile, tablet, and desktop
- Optimized frontend performance
- Production ready deployment on Vercel

## Technology Stack

- Next.js
- TypeScript
- Tailwind CSS
- TanStack Query
- React Hook Form
- Zod
- Axios
- Lucide React
- Vercel
